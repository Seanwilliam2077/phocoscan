# 小芽扫描 · 种一颗风景果

日期：2026-10-26。当前用户批准的立项 Demo 范围；覆盖此前长线养成、九格城镇和六任务展示方案。平台保持 Windows 开发的原生微信小程序，iPhone 微信扫码预览。

## 一轮体验

目标：一株植物，三次约 20 秒的真实扫描，亲手播种、浇水、收获。单次扫描已有风景回忆；完整演示目标 3–5 分钟，实际取决于拍摄与网络上传。场景既可室内也可室外，不要求专门寻找水、阳光或植物。

| 阶段 | 玩家操作 | 提交成功后 |
| --- | --- | --- |
| 播种 | 扫描身边喜欢的角落；将解锁的种子拖进土里，也可点按播种 | 小芽发芽，实际视频封面成为背景 |
| 照料 | 第二次扫描后，按住水壶浇水 | 长出新叶与花；可滑动切换真实风景 |
| 收获 | 第三次扫描后，将果实拖进篮子，也可点按收果 | 打开风景果，查看本轮最多三份真实回忆，完成一轮种植 |

点摸小芽有回应，不发额外成长。界面只有一株植物、当前工具、当前主要动作，回忆和设置为次要入口。扫描中角色只作陪伴和移动提示，不追逐屏幕目标、不报告未经测量的覆盖率或质量。

## 这次扫描怎么拍

目标是同一小场景的连续、多视角观察，不要求绕场景一圈。手机单相机录像提供的是不同时刻的视角，不是同步多相机标定数据。

1. 找一处有前后层次的静态角落，例如桌沿和后面的墙角、花坛和后面的建筑。选一个持续看得见的固定参照。
2. 先站稳，让参照留在画面中；向有空地的一侧慢慢移动一小步，镜头仍看着同一处。不要只站在原地转动手机扫一大片。
3. 再略换一个斜角，仍保留同一参照。约 20 秒是体验提示，随时可以结束；最长录制 40 秒。不要求完成整圈，也不要求走远或倒着走。

录制页只突出当前动作和三步方向提示，由玩家点击下一步推进，20 秒只是时长提醒。`guidanceStamps` 仅表示提示展示和切换时间，不表示用户走过的轨迹、视角数量或质量通过。当前不测量实际运动、重叠率、清晰度、覆盖度、尺度或相机位姿。

后续 feed-forward 路线可以从原视频按时间抽帧，再检查清晰度、共同可见区域及视角差异；保留帧时间与原视频来源。一份原片既可形成视频片段，也可形成重建候选帧集，后续两条数据管线分别验收。不能把模型推断的几何当作实测真值，也不能仅凭拍完三步判定“多目已足够”。本版只完成采集闭环。

路线参考：[VGGT](https://vgg-t.github.io/) 接收一个、少量或多个视角；[Flash3D](https://arxiv.org/abs/2406.04343) 探索单图前馈重建。这说明后端输入形式取决于最终模型；此 Demo 保留连续原片，避免提前绑定必须完整环绕的采集规则。

## 相机错误与原片恢复

相机打开、录制、保存和读取文件信息是不同阶段。视频时长或尺寸暂未读到，不等于画面缺少信息。失败提示应说明阶段并保留具体错误，不能统一归因于权限或要求重拍。

录制返回原片后优先持久保存。真实时长和尺寸未读全时，草稿仍可预览并重新读取，不能用页面计时、预设分辨率或猜测帧率补齐。未取得有效文件信息前阻止网络提交；不因此解锁农场成长。取得信息后沿用原片和原采集 ID 重试。

## 状态与真实数据

- 录像与索引先保存本机；明确提交后才连接、上传并取得服务器奖励回执。
- 只有 `in_app_rgb`、已提交且来源与奖励 ID 对应的实际回执解锁养成操作。外部模型导入、计时、草稿、拍摸和重复提交不能替代。
- 三个阶段动作顺序固定为 `plant / water / harvest`。每份奖励与会话最多消费一次；交互重复触发、退出重进不重复奖励。
- `state.farm` 与已有 schema-2 存档兼容。删除采集保留已经获得的虚拟成长，但对应影像须变为缺失占位；不能读回已删除数据。
- 背景和收获回忆只使用实际采集封面、视频。缺少本机文件时说明缺失，不插入样片冒充用户扫描。果实外观属于虚拟游戏内容。
- 已有后台接收和私有存储接口保持不变。本版不自动重建 3DGS，不证明训练数据可用性。

## 验证重点

1. 新用户能直接开始扫描，断网仍能拍摄并保留草稿。
2. 真实提交成功后回首页，出现本阶段工具；手动操作才成长。
3. 浇水中松手、切后台或退出页面，不产生未完成的成长；重复触发不多发。
4. 第一份和第二份风景能切换；第三次收获能看到最多三份真实回忆。
5. 退出重进保持阶段；重新提交同一视频不产生新的阶段机会。
6. 删除采集或释放本机副本后，不显示已经不存在的封面、视频。
7. 工程测试使用隔离临时数据；编译、模拟器和 iPhone 验收分别记录。

立项观察：第一次体验是否让人理解“我拍到的内容进入了游戏”，是否主动开始第二次，是否完成第三次并愿意展示收获。当前不评估七日留存。

## 演示环境

现有 GitHub Codespaces 地址是开发测试后端，休眠、端口访问和地区网络可能影响手机上传。正式演示前要核对服务健康以及本次上传的实际接收记录。此前用户已反馈手机上传与成长成功，但默认云端未找到对应记录，仍不能把该反馈等同于服务端存储已独立验收。迁移到微信云开发需要用户自己的正式 AppID 和云环境；本次不擅自开通套餐。

本次具体测试结果与新预览码见交付时的验证记录。模拟器没有手机摄像头能力，不能替代 iPhone 真机体验。
