# 本机主体训练与增密验收（2026-11-12）

同日后续：漂浮/底部散点、主体副本和耗时优化见 [v4 验证记录](ON-DEVICE-TRAINING-V4.md)。下文保留 v3 的原始对照。

用户授权先做主体优先、自适应增密，用扫描 15 的企鹅对比，保留原素材、已完成结果及断点恢复。本轮只修改 phocoscan 手机端，没有云端任务或服务器变更。界面继续使用原本的本机版行及省略号菜单。

## 实现

- `TrainingSubject.swift` 在原始相机坐标中投影扫描锚点，调用已有前景实例分割选择主体。照片、相机内参/位姿、LiDAR 种子完全不裁剪或改写。遮罩与 RGB 使用相同缩放和方向，作为独立权重进入损失。空间模式不启用主体权重。
- 有效主体帧分配 85% 前景、15% 背景损失质量，按实际遮罩面积归一化；软边缘保留。权重同时进入 L1 和 SSIM 的目标及解析梯度，包括相邻 SSIM 窗口的贡献。无有效遮罩的帧使用原有全图损失；少于 80% 有效帧（至少 8 帧）会报错，保留素材和结果。
- 分割仅在准备阶段运行。派生遮罩逐帧原子保存到独立 `ondevice.resume/subject/`，摘要绑定原始输入、分析文件和每张遮罩。恢复只读已保存字节，缺失/变化则拒绝继续，不在一个训练会话中重新猜测主体。
- Metal 在像素梯度抵消之前累积绝对图像平面梯度。每 100 步统计真实可见贡献，从第 300 步到前 70% 迭代进行有界增密：平均分数至少 0.0008、至少两次观测、透明度大于 0.02；每轮至多增加当前点数 10%。容量取现有内存计划与种子数两倍的较小值，至多 250k。tile-pair 达预算的 2/3 或训练 Metal 缓冲达预算的 3/4 时不再增密。
- 较大高斯沿旋转后的最长轴拆为两个，尺度除以 1.6；较小高斯复制并补偿透明度/尺度。保留旧的低透明度重分配。没有叠加 opacity reset。此为自有的有界混合策略，不宣称完整复现某个论文训练器。
- 参数、Adam 和临时缓冲预留受限容量，GPU 按活跃点数运行。增长时保留无关点的 Adam 状态，清空新点/修改点的 Adam，迁移活跃布局。检查点新增密度累计状态并保存实际点数。旧六缓冲 v1 检查点仍使用原配置；新七缓冲为 v2。旧暂停任务不会中途切到新算法。
- 两副本的透明度积分使用代数等价的闭式表达，避免每次做 129 个数值积分采样。既有温控、低电量节流、前台 GPU 门控、原子检查点和带旧结果归档的发布机制保持有效。

## 扫描 15 的受控实机对比

iPhone 16 Pro Max；同一份企鹅素材，同一 113 帧、768×576、75,593 种子，同一外部固定视角顺序/随机种子，各 3,000 步。14 个视角均不参加训练。所有 113 帧分割有效，摘要相同。比较旧 v2 算法重新训练出的基线与新策略，**不是把原先手机里的结果当成相同随机条件下的基线**。

先运行的仅复制方案出现细长漂浮点及较高内存/耗时，未发布。修正大高斯拆分后完成第二轮；第二轮最终导出 PLY 重新载入，评价全部 14 个留出视角（包括后半圈）：

| 指标 | 原算法基线 | 主体优先 + 增密 |
|---|---:|---:|
| 主体 MAE（低为好） | 0.059262 | 0.046638（下降 21.3%） |
| 主体 PSNR | 21.185 dB | 23.346 dB |
| 全图 MAE | 0.038105 | 0.039618 |
| 全图 PSNR | 23.759 dB | 23.408 dB |
| 训练活跃点数 | 75,593 | 151,186 |
| 导出高斯数 | 66,864 | 133,535 |
| 实验计时 | 80 秒 | 372 秒 |

计时包括训练后评价/输出，新策略还在第 1499 步保存、释放训练器并恢复；不包括分割准备。不是整机内存峰值、耗电或标准跑分。最后的闭式积分优化在第二轮之后加入，已通过数学/GPU回归，**未再次进行整轮实景计时**；不能用它宣称未经测量的加速。

对比图为同视角真实渲染，仅统一旋转，不生成或修饰画面。正面、侧面和后半圈均看到黄毛及身体细节变清楚，仍有漂浮细丝、背景/支撑面误差。背景拟合有所退步是主体权重的实际取舍；更高主体 PSNR 不是所有漫游角度几何正确的证明。

## 仍有限制

SH0、固定 ARKit 位姿和只用于初始化的 LiDAR 不变；未加入深度损失、逐点近邻尺度初始化或位姿微调。分割不一定在所有反光物体、细毛、人像上稳定，失败会明确停止。内存上限不是操作系统预留内存，长时间温控可能使训练更慢。此次改善仅由扫描 15 证明；空间和人像仍需各自实际素材对照。

方法依据与之前的逐项研究见 [v2 研究记录](ON-DEVICE-TRAINING-V2.md) 中的原始 3DGS、gsplat Default/AbsGS/MCMC、Taming 3DGS 主来源链接；无第三方提取代码导入。
