## 一、第一次打开与纯建设

1. 安装启动。填写小站名、选择主题；断网时仍能查看和布置免费卡片。
2. 放入口、邮局、路卡，旋转直路/三岔路。连接正确与断开时居民反馈必须不同，不能只是动画。
3. 退出 App 再打开，检查名字、卡片、旋转、位置都保留。
4. 在设置中连接正确的后端；错误地址应有可读错误，不能清空本地存档。不同后端不能沿用另一后端的用户 token。

## 二、室内真实数据闭环

1. 领取“第一盏暖灯”，选择有权拍摄的室内局部场景。首次拒绝相机权限，确认能返回或去系统设置恢复。
2. 选择原生采集。录制时缓慢平移，三次提示分别覆盖正面、侧面、地面；不把点击提示当作质量已验证。
3. 保存并预览，核对原片没有按钮/游戏 UI/音频。记录真实时长、尺寸、fps；没有位姿文件是本版的正确状态。
4. 断网提交一次。重新打开 App，原视频和同一个 session 应仍存在；恢复网络后重试。
5. 成功提交并领取基础卡。连续点领取/重复上传，卡数量不应重复增加。
6. 操作者导出该 session 的采集包，确认 manifest 的来源、缺失字段、原片和 session ID；用确实支持该输入的工具重建。
7. 将实际产生的 Gaussian PLY/.splat 导回该 job，记录工具及版本、耗时/费用。文件检测只说明结构支持，不等于几何质量合格。
8. 手机刷新任务，进入结果，测试旋转、缩放、重置、退出再进入。截图及日志记录内存、耗时、卡顿、发热。
9. 放置对应卡片，退出重进保持状态。记录 session / asset / reward ID。

## 三、室外与 Scaniverse 转接

局域网后端测试时，先在离开 Wi-Fi 前创建并保存任务；外出离线拍摄，回到 Wi-Fi 后导入/提交。未部署公网 HTTPS 时，不把电脑回环地址当成街景现场可用的服务。

1. 选“休息区”任务，记录人少、安全、可拍摄的一小片室外街角；不要把整条街一次拍完当作目标。
2. 选择外部扫描路径。离开游戏并重启后，任务仍显示等待导入。
3. 在 Scaniverse 实际扫描处理该地点，导出受支持的真实 Gaussian PLY/.splat 到“文件”。
4. 回游戏导入；取消选择、无权限文件、普通点云和损坏文件应可重试，不发奖。
5. 正确文件导入后可看、可领卡、可放置；同一文件重试不重复发卡。
6. 来源应是 external_asset_only；rawDataAvailable=false，poseSource=none，双用途仍未评估。不能把其他时间另拍的视频算成本次同源数据。

## 四、故障恢复、补采与删除

- 相机录制时切后台或接来电：已有可用片段应被保存或明确报错，不显示虚假已上传。
- 上传中断和服务重启：可使用原 session 重试；未成功写入的临时文件不应出现 ready。
- 操作者标记处理失败：游戏卡保留，结果详情提示原因；重试操作可重新排队。
- 补采入口生成独立 session，parentSessionId 指向本人的原场景；未实际配准前不显示“已融合”。
- 大模型超限制返回具体错误；导入失败不能卡死整个游戏。真实真机记录小、中、大三个规模，不把 Windows 结构测试当性能数据。
- 删除采集时，确认后端原片、模型及相关引用已删除；本地缓存/草稿相应移除，已有卡变为纯虚拟卡。注意手机“文件”中的外部导出原件及操作员曾下载的副本需分别管理。

## 五、完整玩法与试验

完成纯建设章节，满足居民愿望，完成庆典并选择下一章。不得使用修改日期、等待七天或新扫描来绕过本应可纯建设完成的目标。

首轮邀请 5–8 位知情成年人试用，不要求连续每天拍摄。记录：首次成功采集人数、获得并放置卡片人数、查看来源匹配结果人数、次日主动再打开/纯建设人数、主动第二次采集人数、视频/模型有效率、每个合格样本人工分钟数。先看失败原因与访谈，样本量不足以证明规模化留存或训练收益。

## 完成判定

- **本地工程完成**：后端正常运行，接口测试通过，Mac 上实际编译成功。
- **手机闭环完成**：同一部 iPhone 真正安装运行，室内、室外各一条来源可追溯闭环通过。
- **数据双用途完成**：同源母数据经视频与机器人两套独立标准验收；本 MVP 不自动满足此项。
